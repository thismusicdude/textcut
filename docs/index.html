Text editing

Your transcript is your timeline

Drop a video into the window. whisper.cpp transcribes it locally, and every word is linked to its exact position in the footage. Select words by clicking or dragging, press Delete, done. Press it again to bring them back.

  • Precise word boundaries from DTW timestamps plus level analysis – quiet onsets of neighbouring words survive the cut.
  • Search for a word or phrase and delete every match at once.
  • Words Whisper may have invented (barely any audio underneath) are underlined in yellow.

Silence & filler words

One click for tighter takes

ffmpeg's silencedetect finds every pause. Remove silence automatically cuts them from all clips, with adjustable threshold, minimum duration and padding. Filler words like “um” and “uh” go just as fast.

  • Verbatim mode makes Whisper keep fillers, repetitions and slips of the tongue.
  • Filler lists for 10 languages (de, en, fr, es, it, nl, pl, pt, tr, uk), editable in Settings.
  • Smooth audio fades at every cut, with five curve shapes – the timeline length stays the same.

Subtitles

Captions that follow every cut

Burn subtitles straight into the video – the text comes from the transcript, so deleted words disappear from the captions too. Pick a preset (Classic, Social Media, Box) or tune font, size, outline, colours and line length yourself.

  • Highlight the word currently being spoken.
  • Sizes are relative to video height, so 16:9 and 9:16 look equally good.
  • Also exports SRT files with matching timing.

Export

Every format in a single pass

Tick everything you need – landscape, vertical 9:16 for Reels, TikTok and Shorts, square, 4:5 – and TextCut renders them all at once. Other aspect ratios are letterboxed or cropped to fill.

  • H.264, H.265, ProRes 422 and hardware H.264 (VideoToolbox, NVENC, Quick Sync, AMF).
  • Audio-only export as MP3, M4A, WAV or FLAC, optionally normalised to −16 LUFS.
  • Preview and export share the same render graph – what you see is what you get.

Audio projects

Built for podcasts, too

Start an audio project for podcasts, interviews and voice-over. You get audio tracks only, a magnetic main track and cuts that snap to 10 ms. Instead of a video preview, a player shows the sentence currently being spoken.

  • Video files contribute their audio.
  • Same silence removal, filler removal and fades as in video projects.

And a real editor underneath

Multi-track timeline

Magnetic main track, any number of video and audio tracks. Split, trim, move, duplicate, snap, zoom, markers.

Picture-in-picture

Clips on V2 and above with position presets, size, X/Y, opacity and border.

Clip transitions

Crossfade or dip to black/silence, 50–4000 ms, with adjustable audio curve.

Non-destructive

Cuts are stored as source time ranges. Nothing is ever lost, and undo/redo covers everything.

Fast with hundreds of cuts

ffmpeg selects all kept ranges per clip in a single pass, keeping picture and sound in sync.

Private by design

Transcription runs on your machine with whisper.cpp. No account, no upload, no cloud.

Install

Prebuilt archives for every platform are attached to each GitHub release. TextCut also needs ffmpeg (7+) and whisper.cpp. 

brew install ffmpeg whisper-cpp
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
git clone https://github.com/thismusicdude/textcut
cd textcut
cargo run --release

Using the prebuilt binary? It is not signed – run xattr -d com.apple.quarantine textcut once, or allow it under System Settings → Privacy & Security.

  1. Rust: install rustup-init.exe and accept the Visual Studio C++ Build Tools it offers.
  2. ffmpeg: winget install Gyan.FFmpeg, then open a new terminal.
  3. whisper.cpp: download whisper-bin-x64.zip from the whisper.cpp releases and unpack it to C:\whisper (NVIDIA GPU: use the cublas build).
  4. Build and start:
cargo run --release

For a portable setup, put ffmpeg.exe, ffprobe.exe and the whisper files next to textcut.exe or in a bin folder beside it.

# Debian / Ubuntu (24.04 or newer)
sudo apt install build-essential cmake git pkg-config ffmpeg \
  libasound2-dev libxkbcommon-dev libgl1-mesa-dev libwayland-dev \
  libx11-dev libxcursor-dev libxrandr-dev libxi-dev

# whisper.cpp
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build -DBUILD_SHARED_LIBS=OFF   # NVIDIA: add -DGGML_CUDA=1
cmake --build build -j --config Release
mkdir -p ~/.local/bin && cp build/bin/whisper-cli ~/.local/bin/

# TextCut
cd .. && git clone https://github.com/thismusicdude/textcut
cd textcut && cargo run --release

Fedora and Arch package lists are in the README.

On first start, download a Whisper model via Settings → Model → Download. base is fast; small or large-v3-turbo are more accurate.
